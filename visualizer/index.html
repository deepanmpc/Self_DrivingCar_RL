How to use

Explore

Move the eight observation sliders and watch activations propagate through the selected network. Presets give useful driving states.

Scroll to zoom, drag to pan, double-click to fit. Click a neuron or connection for details.

For a static server without MetaDrive:

.venv/bin/python scripts/visualizer_server.py

Live

Start the simulator server:

.venv/bin/python scripts/visualizer_server.py --live --mode baseline

Then open http://127.0.0.1:8765/ and use the Live tab. Pause, step, reset, or use WASD in manual mode.

Load trained weights by adding a checkpoint:

.venv/bin/python scripts/visualizer_server.py --live --checkpoint checkpoints/actor.pt

Saved changes hot-reload without restarting.

Exports

Rebuild the static snapshot after a checkpoint is available:

.venv/bin/python scripts/export_visualizer.py --checkpoint checkpoints/actor.pt --label "PPO 100k"

Reading the graph

Line thickness is the product of weight and source activation. Cyan is positive flow, orange is negative. Node brightness is activation strength.
